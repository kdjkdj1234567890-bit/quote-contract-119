## 결제 연결

`assets/js/payments.js`의 `CONFIG.products` 안 `kmong` / `smartstore` 값에 상품 URL을 넣으면, 그 순간부터 사이트의 유료 버튼이 실제 결제 페이지로 연결됩니다. 비어 있으면 주문 문의 메일로 넘어가고, 메일 본문에 현재 견적 요약(건명·직종·금액·점수)이 자동으로 들어갑니다. 절차는 `launch/payment_setup.md`.
